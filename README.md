## The joke

> IT made me change my password to one with a capital letter, a number, and the will to live — I only have two of those.

## How it works

`main.ts` writes the one-line joke to `/output/entry.txt` — UTF-8 text, one line, about office life, within the 200-character gate.

Run it with:

```sh
node main.ts
```
